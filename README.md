# Chat with OpenAI-compatible API

Простой консольный чат-бот на Python, который работает через OpenAI-compatible API и позволяет переключаться между несколькими моделями, указанными в переменных окружения.

## Что умеет проект

- Запускает интерактивный чат в терминале
- Загружает настройки из файла `.env`
- Поддерживает несколько моделей (`MODEL_NAME1`, `MODEL_NAME2`)
- Хранит историю диалога внутри текущей сессии
- Отправляет сообщения через API совместимое с OpenAI
- Позволяет завершать сессию командой `/exit`

## Структура проекта

- `chat.py` — основной код приложения
- `.env` — настройки подключения к API
- `requirements.txt` — зависимости проекта

## Требования

- Python 3.9+
- Установленные зависимости из `requirements.txt`
- Доступ к OpenAI-совместимому API endpoint

## Установка

1. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

2. Активируйте окружение:

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Windows CMD:

```cmd
.venv\Scripts\activate.bat
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Конфигурация

Создайте файл `.env` в корне проекта со следующими переменными:

```env
OPENAI_API_KEY=your_api_key
OPENAI_API_BASE=https://api.example.com/v1
MODEL_NAME1=gpt-4o-mini
MODEL_NAME2=gpt-4.1-mini
```

Параметры:

- `OPENAI_API_KEY` — ключ доступа к API
- `OPENAI_API_BASE` — базовый URL OpenAI-совместимого сервера
- `MODEL_NAME1`, `MODEL_NAME2` — модели, из которых можно выбрать при запуске

> Обязательно должен быть указан хотя бы один из `MODEL_NAME1` или `MODEL_NAME2`.

## Запуск

```bash
python chat.py
```

После запуска программа попросит выбрать модель и затем откроет интерактивный чат.

Пример:

```text
Выберите модель:
1. gpt-4o-mini
2. gpt-4.1-mini
Номер модели [1-2]: 1
Используется модель: gpt-4o-mini
Чат запущен. Для выхода введите /exit.
Вы: Привет!
Ассистент: Привет! Чем могу помочь?
```

## Примечания

- История чата сохраняется только в памяти во время текущего запуска
- При каждом запуске сессия начинается заново
- Для выхода из чата используйте `/exit`
